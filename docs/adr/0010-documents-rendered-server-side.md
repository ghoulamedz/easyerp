# Documents are rendered and archived on the server

PDFs are generated by the API, stored immutably alongside the document, and served as the archival artifact. The legacy app generated every document in the browser with `dart:html`, which guaranteed nothing about what a customer actually received or kept — its receipts even printed ordered rather than received quantities, and one template numbered every quote `DEV-001`. Server-side rendering also means a document looks the same to every user, in every language, forever, and that the numbering is the same numbering that appears on the page.
